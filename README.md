# Guide VoiceStudio par Entre Deux Commits

Guide illustré en français pour installer VoiceStudio sur Windows x64, préparer les modèles et tester une première voix.

Le site est une page HTML statique adaptée au téléphone. Les captures peuvent être agrandies ; une version PDF est téléchargeable. Aucun compte, outil de suivi ou service externe n’est utilisé par le site.

## Guide en ligne

[Ouvrir le guide VoiceStudio](https://entredeuxcommits.github.io/guide-voicestudio/)

## Hébergement GitHub Pages

Dans Settings → Pages, choisir **Deploy from a branch**, puis **main** et **/ (root)**. Le fichier `.nojekyll` permet de publier les fichiers statiques directement.

## Aperçu local

Servir ce dossier avec un serveur HTTP statique, ou ouvrir `index.html`. Aucune compilation ni installation de dépendances nécessaire.
